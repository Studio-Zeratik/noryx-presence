# Security

If you find a security issue in NoryxBot Presence (the code or the official service at
presence.noryxbot.com), please **don't open a public issue**. Write to **contact@noryxbot.com** with
"Security" in the subject, and include:

- what the issue is and where (endpoint, file, version);
- how to reproduce it;
- what an attacker could do with it.

We answer within a few days, keep you informed, and credit you when the fix is out if you wish.
Please give us a reasonable time to fix it before talking about it publicly, and don't access or change
other people's data while testing.
